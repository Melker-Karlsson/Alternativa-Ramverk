* Requirments

.net 10.0 sdk 
Node.js & npm
Angular cli            (npm install -g @angular/cli) to install it globaly


* Starting backend
open a terminal

make sure you're in the corect directory. Should end with (\AlternativProject\Backend\Todo-Api) IF NOT either use cd. to switch current directory or traverse the project to the directory Todo-Api right-click and OPEN in TERMINAL

in terminal type (dotnet run) to run API

If you whant to close the API press ctrl + c in the terminal



* starting frontends

* Angular

make sure you're in the corect directory. Should end with (\AlternativProject\Frontend\todoAngular) IF NOT either use cd. to switch current directory or traverse the project to the directory Todo-Api right-click and OPEN in TERMINAL

type (npm install) to install dependicies

type (ng serve) to start a development server and use the provided link to open the app in a local enviorment
